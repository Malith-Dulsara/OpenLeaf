# Code of Conduct

OpenLeaf follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, and assume good intent. Harassment, insults and personal attacks
aren't tolerated anywhere in the project: issues, pull requests, discussions or any other space.

If you experience or witness unacceptable behaviour, please report it privately to the maintainer through
[a private security advisory](https://github.com/Maith-Dulsara/OpenLeaf/security/advisories/new) or by
contacting [@Maith-Dulsara](https://github.com/Maith-Dulsara) on GitHub. All reports will be handled
confidentially.
